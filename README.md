# XJTU - Verilog CPU Design

单周期、多周期、流水线各 13 条 MIPS 基础指令（可能存在少量bug）

R-R运算指令 `add, addu, sub, subu, and, or, xor, slt, nop`

| OP_code | RS        | Rt        | Rd         | Shamt  | Func   |
| ------- | --------- | --------- | ---------- | ------ | ------ |
| 操作码  | 源寄存器1 | 源寄存器2 | 目的寄存器 | 移位量 | 函数码 |
| 6       | 5         | 5         | 5          | 5      | 6      |

加载指令 `lw`，保存指令 `sw`，分支指令 `beq`

| OP_code | RS        | Rt        | Imm16/Addr16 |
| ------- | --------- | --------- | ------------ |
| 操作码  | 源寄存器1 | 源寄存器2 | 地址/立即数  |
| 6       | 5         | 5         | 16           |

跳转指令 `j`

| OP_code | Addr26   |
| ------- | -------- |
| 操作码  | 26位地址 |
| 6       | 26       |
